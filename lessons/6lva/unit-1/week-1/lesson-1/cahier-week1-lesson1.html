How to run it

Five blocks, five beats each

Every block runs Concept → Model → Practise → Game → Worksheet. Project it, drive it from the keyboard, and let the class call the answers out loud. You press the key they shout.

1–9 choose an answer / place a word
Space next step, or reveal
← → move between beats
R say it again
A / B award a point by hand
Z undo the last point
Backspace take back a word
C timer on / off
M sound on / off
D paper / blackboard
Esc back to the menu
H close this

Teams alternate automatically. A wrong answer opens a steal for the other team. If the browser has no English voice, every audio item still shows its text on Space.
